# Project agent guidance

When changing this storefront, use its product catalog and the supplied design reference as the source of truth. Keep the editorial apparel direction: restrained typography, generous whitespace, warm neutrals, and photography-led product cards. Make the layout responsive and keyboard-accessible; preserve semantic headings, alt text, and visible focus states.

For image-to-code work, map the reference into reusable page sections and existing CSS tokens before adding components or dependencies. Verify the result in the browser at desktop and mobile widths, and check that the rendered product data still comes from the server/API rather than a frontend-only fixture.
